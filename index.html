About

"Making game development fun is the first step to making a game that's enjoyable."

The work is deeply technical and touches many parts of development at once: scripting, VFX, behavior trees, and tools. Whatever the task, the goal stays the same — leave a positive mark on anything worked on.

Professional work

Lords of the Fallen 2

Worked with CI Games in Unreal Engine, managing four enemies including one mini-boss. Set up behavior trees and Blueprint behaviors, then tuned animation to hit the Souls-like gameplay feel the series demands.

Enemy behavior trees

An enemy's behavior tree in Unreal Engine: initialization, then a selector choosing between blocks/parries, priority actions, cooldown-gated attacks, and repositioning based on the blackboard state.

Custom Blueprint behaviors

A Blueprint node graph for a ranged attack: spawning a projectile actor at a transform built from the owning hero's location and rotation, then assigning the result to the enemy's Projectile reference.

Animation tweaking/prototyping

Previewing and tuning an enemy's reload animation montage in Unreal's animation editor, adjusting segment timing (start/end time, play rate, loop count) against the character in the viewport to hit the right feel.

Parallel

Card and deck UX

The deck builder's UX: laid out first as a wireframe mock-up with placeholder cards and copy, then built out with real card art, faction identity, and live deck stats (unit/relic/upgrade/effect counts and a cost curve).

Card rules and implementation management

The card database driving implementation: rules text, flavor text, rarity, faction, type/subtype, attack/health/cost, release pack, and tutorial-card flagging per card, checked against a live in-game card preview.

Paper Heroes

Feature development

Design documentation for the climbing tower feature: theming (platforms as enemy strongholds, conquest flags), tower UX (featured enemies and rewards set in data), data-driven background transitions, and platform tiers by floor.

Workflow tools for prototyping

A spreadsheet-driven map generator for the Gauntlet mode: a lettered/numbered grid of encounter and utility tiles (normal/hard/boss encounters, recruitment, medical zones) with a legend and a Generate Map Data action, checked against the in-game floor layout.

A/B testing

The Firebase architecture behind the game's A/B testing: the backend API and Firebase's real-time database exchanging data, then reaching the frontend web app and Android client over real-time DB sync and Firebase Cloud Messaging.

Dissidia Final Fantasy Opera Omnia

My first experience on a mobile title. Built an automation tool that cut data tasks — work that used to eat significant designer time because of legacy issues — down to minutes.

Settings menu rework

A redesign proposal for the settings menu: consolidating the original's two-panel, all-options-at-once layout into a single panel with left-hand category tabs (Game, Sound, Privacy) and a Restore Defaults action.

Colorblind mode

A colorblind-accessible palette for the gear and abilities screen, checked against a blue-blind (tritanopia) simulation alongside full color, comparing the normal UI palette to the colorblind-mode palette in each case.

Co-op matchmaking QOL

A quality-of-life proposal for co-op mission matchmaking: adding an "Either" option alongside Host and Guest, so a player auto-joins an open party as a guest, or starts as host automatically when no slots are open, instead of guessing which to pick.

Data setup automation

The character event data setup tool referenced above: an Excel/VBA sheet that takes an event ID, its start and end times, the character name, and a reference event to pull global rewards from, then generates the event data in one click.

War of the Visions: Final Fantasy Brave Exvius

Interned ahead of the game's global release, analyzing its data structures and codebase. Developed VBA-based visualization tools for data versioning that stayed in use for the rest of the project's lifespan.

Tutorial flow document

First task on entering Gumi Asia.

Goals

  • Create a document for visualizing the entire tutorial
  • Document used to petition for reducing the tutorial length for global release

Obstacles

  • Existing tutorial was quite lengthy (500+ shots)
  • No access to tools like Adobe Photoshop with batch automation

Results

  • Created two tools using Unity C#
    • First tool took a high-quality screenshot on hotkey press, significantly reducing the time needed to slowly snip the screen
    • Second tool went through all photos in a folder, placed them in an ordered structure, then took a screenshot
  • Inclusive of tool creation time, the task was completed within 3 working days, compared to the original allocation of 10 working days
  • Also completed the extended goal of digging out attached analytics trackers within the week

Data versioning compare tool

A VBA-built comparison tool for versioning the game's character data: diffing old and new spreadsheet exports side by side to catch value changes before each release.

Global ad gacha feature

A rewarded-video gacha system: a fill-up gauge tracks progress toward a free "Video Summon," rewarding players with Gil Snappers, Story Skip Tickets, and Visiore.
